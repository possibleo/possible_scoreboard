# Scoreboard

A modern scoreboard for FiveM servers with QBX, QB-Core, and ESX support.

## Preview
https://www.youtube.com/watch?v=O21HMDQ8aVg

## Installation

1. Download the latest release
2. Extract and drag the folder into your server's `resources` directory
3. Add `ensure possible_scoreboard` to your `server.cfg`

## Dependencies

- QBOX, QBCORE, or ESX framework
- ox_lib

## Features

- Clean, modern UI
- QBX, QB-Core, and ESX support (auto-detection)
- Toggle between RP names and Steam names
- Filter players by job (Police, EMS, Mechanic, etc.)
- Staff tab for admin players
- Player IDs above nearby players when scoreboard is open
- "Peers Behind Curtain" indicator above players viewing the scoreboard
- Staff actions (right-click):
  - Teleport to player
  - Bring player
  - Freeze/unfreeze player
  - Spectate player
  - View player details
- Configurable keybind and command
- Locales
- Customizable theme
